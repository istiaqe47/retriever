Retriever for your browser

Hands your downloads, a page's links, videos and magnet links to the Retriever app.

Install the Retriever app

This extension needs the Retriever app on this computer. On Arch or CachyOS, in the folder you extracted it to:

makepkg -si

Then open Retriever once: it sets up the connection for every browser it finds.

“Retriever isn't installed”

The browser can't find Retriever's connection (its native messaging host).

  1. Install Retriever (above), and open it once.
  2. Restart the browser.
  3. Some browsers can't start Retriever's helper: Zen and other Firefox-based browsers, and browsers installed as a Flatpak or a Snap. Keep Retriever open: they connect to it directly. The first time, Retriever asks whether to allow the browser: choose Allow.

“Retriever wasn't allowed to connect”

Retriever asked whether to connect this browser, and the answer was Don't Allow. Open the extension's popup again: Retriever asks once more. To start over for every browser, use Forget in Retriever's Preferences → Browsers → Connected Browsers.

Retriever can't be found

Open Retriever once (it registers its connection with each browser), then restart the browser.

“Retriever doesn't accept this copy of the extension”

The connection only answers Retriever's own extension. Update Retriever: an older version doesn't know this copy of the extension yet.

“Retriever didn't start in time”

Start Retriever from the app grid, then try again. If it never starts, run retriever in a terminal to see why.

“Update Retriever”

This extension asked for something your Retriever doesn't do yet. Update Retriever.

A protected video

Videos protected against copying (DRM, as on Netflix) can't be downloaded.

The video is gone

The page changed, or the video ended. Reload the page and try again.

Too many links

The page has more links than the browser can hand over at once. Use Retriever's Grab Links (the arrow beside +) with the page's address instead.

An address Retriever can't download

Retriever downloads http, https, ftp and ftps addresses, and magnet links. A blob: or data: address exists only inside the page: it stays with the browser.

YouTube

Retriever downloads YouTube's videos with yt-dlp (installed with it). For all of YouTube's qualities, install Deno: sudo pacman -S deno.

Firefox, Zen, LibreWolf, Floorp

Firefox installs only add-ons signed by Mozilla. Sign this one once with your free addons.mozilla.org account (Retriever's sign-firefox.sh), then open the signed .xpi in Firefox. LibreWolf can also install it unsigned.

Chrome, Chromium, Brave, Vivaldi, Edge, Opera

  1. Open chrome://extensions (Brave: brave://extensions).
  2. Turn on Developer mode, top right.
  3. Load unpacked, and choose /usr/share/retriever/extension/chromium.
